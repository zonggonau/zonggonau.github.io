# Portfolio Theme Options

Berikut adalah 3 opsi theme profesional alternatif untuk portfolio Anda. Setiap theme memiliki karakteristik dan color scheme yang berbeda.

## Current Theme: **Tech Purple-Blue** (styles.css)

- **Color Scheme**: Gradient biru-ungu (#667eea → #764ba2)
- **Style**: Modern glassmorphism dengan gradient backgrounds
- **Vibe**: Tech-focused, innovative, DevOps-oriented
- **Best For**: DevOps, Cloud Engineers, Tech Startups

---

## Theme Option 1: **Professional Dark** (styles-dark.css)

### Karakteristik:

- **Color Scheme**: Dark navy dengan accent cyan/teal (#0a192f → #64ffda)
- **Style**: Minimalist, clean, high contrast
- **Vibe**: Sophisticated, corporate, premium
- **Inspiration**: GitHub dark theme, developer portfolios

### Color Palette:

```
Background: #0a192f (Navy Dark)
Secondary: #112240 (Navy)
Text Primary: #ccd6f6 (Light Gray)
Text Secondary: #8892b0 (Muted Gray)
Accent: #64ffda (Cyan/Teal)
Accent 2: #00d9ff (Bright Cyan)
```

### Features:

- Subtle animations dengan glow effects
- Card dengan border glow on hover
- Monospace fonts untuk technical feel
- Terminal-inspired design elements

---

## Theme Option 2: **Corporate Blue** (styles-corporate.css)

### Karakteristik:

- **Color Scheme**: Professional blue dengan white (#0066cc → #ffffff)
- **Style**: Clean, corporate, trustworthy
- **Vibe**: Business-oriented, professional, reliable
- **Inspiration**: LinkedIn, corporate websites

### Color Palette:

```
Background: #ffffff (White)
Secondary: #f5f7fa (Light Gray)
Text Primary: #1a1a1a (Almost Black)
Text Secondary: #666666 (Gray)
Accent: #0066cc (Corporate Blue)
Accent 2: #0052a3 (Dark Blue)
```

### Features:

- Flat design dengan subtle shadows
- Professional typography (Roboto/Open Sans)
- Clean lines dan geometric shapes
- Emphasis on readability dan clarity

## Theme Option 3: **Creative Gradient** (styles-creative.css)

### Karakteristik:

- **Vibe**: Creative, energetic, modern

Background: #ffffff (White)

## Cara Menggunakan Theme Alternatif:

### Opsi 1: Ganti File CSS

1. Backup `styles.css` saat ini
2. Rename theme yang dipilih menjadi `styles.css`
3. Refresh browser

### Opsi 2: Link Theme Baru

Ubah di `index.html`:

```html
<!-- Ganti -->
<link rel="stylesheet" href="styles.css" />

<!-- Dengan salah satu: -->
<link rel="stylesheet" href="styles-dark.css" />
<link rel="stylesheet" href="styles-corporate.css" />
<link rel="stylesheet" href="styles-creative.css" />
```
